# Welcome

This page is rendered from `resources/content/home.md`. Edit it directly or replace it with a Blade view by setting `use_markdown_home` to `false` in `config/client.php`.

## Getting started

- Add pages as `.md` files under `resources/content/`
- Configure navigation in `config/client.php`
- Override layouts and components in your client repo
